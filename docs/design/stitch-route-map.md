# Stitch Route Map (Fallback)

This fallback mapping is used until Stitch screen payloads are fetched.

## Routes

- `/overview` -> Overview dashboard screen
- `/ledger/search` -> Ledger search/list screen
- `/ledger/add` -> Ledger add/import screen
- `/chat` -> AI chat screen

## Notes

- Once Stitch payloads are available in `stitch-project.json` and `stitch-screens.json`, replace this file with exact screen-id to route mapping.
